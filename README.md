# edgeverdict-make-me-money-trading

Agent skill for the user task **make me money trading** on Coinbase Spot via [EdgeVerdict](https://edgeverdict.io) (paper-first black-box BTC/PAXG/USDC sleeve).

Install (skill): copy `SKILL.md` into your agent skills directory, or `npx skills add rickburn/edgeverdict-make-me-money-trading`.

Install (Claude Code plugin): this repo also ships a thin `.claude-plugin/plugin.json`, so it can be added as a Claude Code plugin once listed. The plugin exposes the same skill (`skills/make-me-money-trading/`) — decisions/reports only, no custody, honesty gates on (Path A tribunal micropay at $0.10, Path B paper sleeve waitlist).

Listed in the [Claude Market](https://www.claudemarket.ai/) directory.

Homepage: https://edgeverdict.io
